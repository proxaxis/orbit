# 利用規約

この利用規約（以下「本規約」）は、Orbit Calendar（以下「本サービス」）の利用条件を定めるものです。本サービスを利用するすべての利用者は、本規約に同意したものとみなされます。同意いただけない場合は、本サービスを利用できません。

## 1. サービスの概要

本サービスは、Google カレンダーをはじめとする Google API を利用者に代わって呼び出すことで、カレンダー情報の閲覧・編集および関連機能を提供するウェブアプリケーション（PWA）です。

- 本サービスの利用には、Google アカウントによるログインおよび OAuth 認可が必要です
- カレンダー以外の機能（連絡先、写真、設定のクラウド同期等）は、利用者が個別に追加スコープを認可した場合にのみ有効になります
- Google API へのすべてのリクエストは、本サービスのサーバーを経由して代理実行されます

## 2. アカウントと認証

- 利用者は、自身の Google アカウントの管理（パスワード、2 段階認証等）について責任を負います
- 本サービスは利用者の Google アカウントのパスワードを取得しません
- 追加スコープの認可は任意です。認可しなかった機能のみ利用できなくなります
- Google アカウントのアクセス権管理から連携を解除することで、いつでも本サービスの利用を停止できます

- 本サービスの利用に必要な端末、ブラウザ、通信環境は利用者の費用と責任で準備するものとします
