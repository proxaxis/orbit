# プライバシーポリシー

Orbit Calendar（以下「本サービス」）は、利用者のプライバシーを尊重し、個人情報の保護に関する法律（個人情報保護法）その他の関連法令を遵守して、利用者の情報を取り扱います。本ポリシーは、本サービスにおける利用者情報の収集・利用・保管・削除について説明するものです。

本サービスを利用することで、利用者は本ポリシーに同意したものとみなされます。

## 1. 収集する情報

### 1.1 Google アカウントおよび認証情報

- Google アカウント ID（ID トークンの `sub` クレーム）
- OAuth 2.0 アクセストークンおよびリフレッシュトークン
- 利用者が認可したスコープ

本サービスは、利用者の指示に基づき Google API（Google カレンダー、Google People API、Google フォト関連 API、Google ドライブ）に代理でアクセスするため、これらの認証情報をサーバー上のデータベースに保管します。クライアントから Google API への直接アクセスは行わず、すべての API 呼び出しは本サービスのサーバーを経由します。

### 1.2 セッション情報

- セッション識別子（署名付き Cookie `session_id` に格納。HttpOnly・Secure・SameSite=None 属性付き、有効期間 30 日）

### 1.3 API リクエストの記録

- プロキシしたリクエストのサービス名、HTTP メソッド、URL、レスポンスステータス、リクエスト時刻および処理時間（障害調査・保守のためのログ）
- プロキシしたリクエスト・レスポンスの内容（非同期処理のため一時保管され、完了後最長 10 分で削除されます）

### 1.4 プッシュ通知に関する情報

- プッシュ購読情報（エンドポイント URL、購読用暗号鍵）
- 通知のスケジュール（送信予定時刻）と通知内容（タイトル等）

これらは通知の送信までサーバー上に保管され、送信後に削除されます。購読情報自体はセッションと同じ有効期間（30 日）で管理されます。

### 1.5 場所情報の照会

- 利用者が入力した Google マップの URL

場所名・住所を抽出するためにサーバー側で当該 URL を取得します。抽出結果（場所名・住所）は最長 6 時間、サーバー内メモリにキャッシュされます。

### 1.6 本サービスが収集しない情報

- 広告配信、行動追跡、アクセス解析（アナリティクス）のための情報は収集しません
- トラッキング目的の Cookie または第三者 Cookie は使用しません
- Google API から取得したデータ（カレンダー、連絡先、写真等）を、利用者のリクエストの代理処理に必要な範囲を超えて保存・利用しません

## 2. 利用目的

収集した情報は、以下の目的でのみ利用します。

1. Google API への代理アクセス（本サービスの中核機能の提供）
2. ログイン状態の管理および認証
3. 利用者が設定したプッシュ通知の送信
4. 障害対応、不正利用の防止等のサービス保守・運営

## 3. Google ユーザーデータの取り扱い

本サービスにおける Google API から取得した情報の利用、および他のアプリケーションへの転送は、[Google API サービスのユーザーデータポリシー](https://developers.google.com/terms/api-services-user-data-policy)（Google API Services User Data Policy、Limited Use 要件を含む）に従います。

- Google API から取得したデータを第三者に販売しません
- 広告目的、信用調査、採用選考等の目的で利用しません
- 人によるデータの閲覧は、利用者の明示的な同意がある場合、セキュリティ上または法令上必要な場合に限定します

## 4. 第三者への提供・委託

利用者情報は、以下の場合を除き第三者に提供しません。

- **Google**: 利用者の指示に基づく API プロキシのため、リクエスト内容を各 Google API に送信します
- **プッシュ配信サービス**: プッシュ通知の送信のため、通知内容が利用者のブラウザ・OS ベンダーのプッシュ配信サービス（Google FCM、Mozilla、Apple 等）を経由します
- **法令に基づく場合**: 裁判所・行政機関等からの適法な開示請求があった場合

## 5. データの保管場所と保持期間

利用者情報は本サービスのサーバー上のデータベース（Realm）およびインメモリストア（Redis）に保管されます。

| データ | 保持期間 |
| --- | --- |
| OAuth 認可フローの state | 10 分 |
| セッション | 発行から 30 日 |
| API リクエストの処理結果 | 完了後 10 分 |
| プッシュ購読・通知スケジュール | セッションと同じく最大 30 日（送信済み通知は送信時に削除） |
| API リクエストログ | サービス運営に必要な期間 |
| OAuth トークン・Google アカウント ID | 利用者のセッションがすべて終了するまで |
| 場所情報のキャッシュ | 最長 6 時間（サーバー内メモリのみ） |

## 6. データの削除

- **ログアウト**により、その端末のセッションとプッシュ購読・通知スケジュールが削除されます
- 利用者のセッションがすべて終了した時点で、保管している OAuth グラント（アクセストークン・リフレッシュトークン）を削除し、Google 側でもリフレッシュトークンの失効（revoke）を実行します
- [Google アカウントのアクセス権管理](https://myaccount.google.com/permissions)から本サービスとの連携を解除することでも、いつでもアクセス権を取り消すことができます

## 7. Cookie について

本サービスは認証目的のセッション Cookie のみを使用します。広告・トラッキング目的の Cookie は使用しません。

セッション Cookie は HttpOnly・Secure・SameSite=None 属性付きで発行され、本サービスのフロントエンドと API サーバーが別オリジンの環境でも動作するよう設計されています。ブラウザの設定で Cookie を拒否した場合、本サービスは正常に動作しません。

## 8. セキュリティ

- OAuth トークンはサーバー上にのみ保管され、クライアントには開示されません
- API プロキシは許可された Google API ドメインへのリクエストのみを転送します（SSRF 対策）
- セッション Cookie は署名付きで、改ざんを検知します
- プッシュ通知のエンドポイントはハッシュ化して管理します

完全なセキュリティを保証するものではありませんが、合理的な技術的・組織的対策を講じています。

本ポリシーは、法令の改正やサービス内容の変更に応じて改定することがあります。変更後のポリシーは本ページに掲載した時点で効力を生じます。重要な変更がある場合は、本サービス上またはその他適切な方法でお知らせします。
